    README

    StudySync is a lightweight student productivity app built with HTML, Tailwind CSS, and vanilla JavaScript.

    1. Download or save the file as index.html.
    2. Open the file directly in your browser, or run a local server from the same folder:
    3. cd your-folder
      python -m http.server 8000
      Then visit http://localhost:8000
    4. All tasks are saved locally in your browser using localStorage.

    Tip: Use StudySync to track study tasks, turn notes into quick quiz practice, and focus with a clean 25-minute Pomodoro timer.
